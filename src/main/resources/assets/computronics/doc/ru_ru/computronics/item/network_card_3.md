# Сетевая карта 3 уровня (NIC Tier 3)

**Сетевая карта 3 уровня** — промышленный сетевой контроллер для компьютеров, серверов и серверных стоек OpenComputers. Значительно расширяет сетевую пропускную способность и снимает аппаратные ограничения стандартных сетевых карт.

Имя компонента: `modem`

## Технические характеристики
- **Jumbo Frames**: Максимальный размер одного пакета увеличен до **65536 байт (64 КБ)** (вместо стандартных 8 КБ), что позволяет передавать целые файлы и таблицы в один запрос.
- **64 открытых порта**: Поддерживает одновременную работу до 64 открытых сетевых портов.
- **Спуфинг адреса отправителя**: Аппаратная поддержка подделки обратного адреса на исходящих пакетах `send` и `broadcast`.

## Методы компонента

- `open(port: number): boolean`  
  Открывает сетевой порт (до 64 активных портов одновременно).
- `close([port: number]): boolean`  
  Закрывает порт (или все открытые порты, если аргумент не указан).
- `isOpen(port: number): boolean`  
  Проверяет, открыт ли указанный порт.
- `maxPacketSize(): number`  
  Возвращает `65536` байт.
- `maxOpenPorts(): number`  
  Возвращает `64`.
- `isSpoofingSupported(): boolean`  
  Возвращает `true`.
- `send(target: string, [source: string], port: number, data...): boolean`  
  Отправляет пакет получателю `target`. При указании второго аргумента `source` адрес отправителя будет подменён.
- `broadcast([source: string], port: number, data...): boolean`  
  Рассылает широковещательный пакет с возможностью подмены адреса источника.
- `getWakeMessage(): string, boolean` / `setWakeMessage(msg: string[, fuzzy: boolean])`  
  Считывает или устанавливает сообщение для пробуждения компьютера по сети (Wake-on-LAN).

## Сигналы (Events)

- `modem_message(localAddress: string, remoteAddress: string, port: number, distance: number, data...)`  
  Сигнал, приходящий компьютеру при получении пакета на открытый порт.

## Пример на Lua

```lua
local component = require("component")
local modem = component.modem

modem.open(1234)

-- Отправка пакета с поддельным адресом шлюза
modem.send("сервер-базы", "главный-роутер", 1234, "СЕКРЕТНЫЕ_ДАННЫЕ")

-- Широковещательный запрос с подменой источника
modem.broadcast("администратор", 1234, "PING")
```
