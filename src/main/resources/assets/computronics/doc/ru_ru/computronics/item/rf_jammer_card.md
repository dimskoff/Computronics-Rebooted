# Карта глушилки радиосигналов

**Карта глушилки радиосигналов (RF Jammer Card)** — карта расширения для компьютеров, переносных планшетов, дронов и роботов, генерирующая электромагнитные помехи для подавления и искажения беспроводной сетевой связи в настраиваемом радиусе.

Имя компонента: `rf_jammer`

## Методы

- `setEnabled(enabled: boolean): boolean`  
  Включает или выключает передачу глушащего радиосигнала.
- `isEnabled(): boolean`  
  Возвращает текущее состояние глушилки (активна/неактивна).
- `setFrequency(freq: number): number`  
  Устанавливает целевую радиочастоту (`0` — глушение широкого спектра).
- `getFrequency(): number`  
  Возвращает текущую подавляемую частоту.
- `setPower(power: number): number`  
  Устанавливает мощность передатчика помех (`1.0` - `100.0`).
- `getPower(): number`  
  Возвращает текущую мощность передатчика.
- `getRadius(): number`  
  Возвращает эффективный радиус подавления в блоках (`power * 0.75`).
- `isAreaJammed([freq: number]): boolean`  
  Проверяет, находится ли текущая позиция в зоне действия активных помех.

## Пример на Lua

```lua
local component = require("component")
local jammer = component.rf_jammer

-- Включаем широкополосное подавление в радиусе 30 блоков
jammer.setFrequency(0)
jammer.setPower(40)
jammer.setEnabled(true)
print("Мобильное глушение активно! Радиус: " .. jammer.getRadius() .. "м")
```
