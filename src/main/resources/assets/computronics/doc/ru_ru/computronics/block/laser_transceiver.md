# Лазерный трансивер (Laser Transceiver)

**Лазерный трансивер** создаёт высокоскоростной направленный оптический канал связи между двумя блоками на расстоянии до 64 блоков без использования физических кабелей. Также работает как охранная оптическая растяжка.

Имя компонента: `laser_transceiver`

## Наведение и работа
Два трансивера должны быть направлены лицевыми панелями навстречу друг другу по прямой линии видимости. При установке связи сети обоих компьютеров объединяются, автоматически передавая пакеты.

## Оптическая сигнализация
Если игрок или моб пересекает лазерный луч:
1. Связь кратковременно разрывается (`isBeamBroken() == true`).
2. Компьютеру немедленно отправляется сигнал тревоги `tripwire_triggered`.

## Методы компонента

- `isConnected(): boolean`  
  Возвращает `true`, если связь с противоположным трансивером установлена и луч непрерывен.
- `getDistance(): number`  
  Возвращает дистанцию до связанного трансивера в блоках.
- `isBeamBroken(): boolean`  
  Возвращает `true`, если луч в данный момент перекрыт сущностью.

## Сигналы (Events)

- `tripwire_triggered(entity: string, distance: number)`  
  Срабатывает в момент пересечения луча кем-либо, передавая имя нарушителя и дистанцию от блока.

## Пример на Lua

```lua
local event = require("event")
local component = require("component")
local laser = component.laser_transceiver

print("Связь: " .. tostring(laser.isConnected()) .. ", Дистанция: " .. laser.getDistance())

while true do
  local _, target, dist = event.pull("tripwire_triggered")
  print(string.format("ТРЕВОГА! Нарушитель: %s на дистанции %.1fм!", target, dist))
end
```
