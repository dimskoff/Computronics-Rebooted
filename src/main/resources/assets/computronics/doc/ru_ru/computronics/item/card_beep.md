# Звуковая карта (Beep Card)

Карта расширения для компьютеров, роботов и планшетов, генерирующая прямоугольные синтезаторные волны заданной частоты.

## Имя компонента
`beep`

## Методы

* `beep(frequency: number, duration: number): boolean`
  Генерирует звуковой тон на частоте `frequency` (от 20 до 2000 Гц) длительностью `duration` секунд (от 0.05 до 5.0 с).
* `getFrequency(): number`
  Возвращает последнюю частоту.
