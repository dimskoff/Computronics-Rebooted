# Карта самоуничтожения (Self-Destruct Card)

**Карта самоуничтожения** — термическая плата подрыва, устанавливаемая в компьютеры, серверы или роботов. Позволяет мгновенно или по таймеру взорвать корпус для защиты конфиденциальных данных и алгоритмов от перехвата противником.

Имя компонента: `self_destruct`

## Методы компонента

- `start(fuse: number): boolean`  
  Взводит таймер взрывателя на указанное количество секунд (`fuse`).
- `time(): number`  
  Возвращает оставшееся время до подрыва в секундах (или `-1.0`, если взрыватель не взведён).
- `detonate([power: number]): boolean`  
  Мгновенно подрывает системный блок (сила взрыва по умолчанию: 3.0, максимум: 8.0).
- `setTime(ticks: number[, power: number]): boolean`  
  Устанавливает таймер в игровых тиках (20 тиков = 1 секунда) и настраиваемую силу взрыва.

## Программа в OpenOS

В комплекте аддона поставляется утилита `explode`:
```sh
explode 10       # Взвод таймера на 10 сек с выводом таймера на весь экран
explode -s 5     # Скрытый взвод таймера на 5 сек без вывода на монитор
explode -t 15    # Вывод обратного отсчёта прямо в терминал оболочки
```

## Пример на Lua

```lua
local component = require("component")
local sd = component.self_destruct

print("ВЗВОД СИСТЕМЫ САМОУНИЧТОЖЕНИЯ...")
sd.start(5) -- 5 секунд

while sd.time() > 0 do
  print(string.format("До детонации осталось: %.1f сек.", sd.time()))
  os.sleep(1)
end
```
