# Магнитные кассеты (Magnetic Tapes)

**Магнитные кассеты** — съемные накопители информации для [Ленточного накопителя](../block/tape_drive.md). Обеспечивают надёжное последовательное хранение аудиофайлов и бинарных данных.

## Уровни и ёмкость

- **Железная кассета**: 131 072 байт (128 КБ)
- **Золотая кассета**: 262 144 байт (256 КБ)
- **Алмазная кассета**: 524 288 байт (512 КБ)
- **Кассета из звезды Незера**: 1 048 576 байт (1 МБ)

## Использование
1. Вставьте кассету в Tape Drive нажатием ПКМ по блоку с кассетой в руке.
2. Управляйте кассетой в OpenOS с помощью утилиты `tape` или через Lua-компонент `tape_drive`.
3. Подписывайте кассету через команду `tape label "Моя Запись"` или метод `tape.setLabel()`.
