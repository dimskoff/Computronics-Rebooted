# Камера (Camera)

**Камера** — оптический сканирующий сенсор, производящий трассировку лучей (raycasting) в пространстве по заданным углам рыскания (`yaw`) и тангажа (`pitch`). Позволяет измерять расстояние и спектрально анализировать блоки.

Имя компонента: `camera`

## Углы направления
- `yaw`: Горизонтальный угол в градусах (`0`–`360`).
- `pitch`: Вертикальный угол в градусах (`-90` строго вниз, `0` горизонт, `90` строго вверх).

## Методы компонента

- `distance(yaw: number, pitch: number): number`  
  Направляет луч на дистанцию до 64 блоков. Возвращает точную дистанцию до первого препятствия или `-1.0`, если блок не обнаружен.
- `scan(yaw: number, pitch: number): table`  
  Производит детальный анализ блока на пути луча. Возвращает таблицу:
  ```lua
  {
    distance = 18.5,
    block = "minecraft:iron_ore",
    hardness = 3.0,
    light = 12
  }
  ```

## Пример на Lua

```lua
local component = require("component")
local cam = component.camera

local info = cam.scan(0, -10)
if info then
  print(string.format("Обнаружен блок %s на расстоянии %.1fм (Твёрдость: %.1f)", info.block, info.distance, info.hardness))
else
  print("Препятствий на пути луча нет.")
end
```
