# Карманный терминал (Pocket Terminal)

Карманный терминал — портативный беспроводной дисплей и пейджер, удерживаемый в руке. Выводит информацию на экран в режиме реального времени на интерфейсе HUD.

## Основные характеристики
* **Управление питанием:** ПКМ в руке переключает питание (ВКЛ / ВЫКЛ).
* **Вместимость батареи:** 20 000 EU. Заряжается на индукционной зарядной панели (Inductive Charger Pad) прямо при нахождении в инвентаре игрока.
* **Разрешение экрана:** 30 символов на 10 строк.
* **Связь:** Беспроводной приёмник OpenComputers на канале по умолчанию `404`.

## Беспроводное API (Lua)
Любой компьютер или робот с беспроводной сетевой картой (`modem`) может передавать команды на терминал:

```lua
local component = require("component")
local m = component.modem
m.open(404)

-- Очистка экрана
m.broadcast(404, "pt", termId, "clear")

-- Вывод текста в координаты (X, Y)
m.broadcast(404, "pt", termId, "set", 1, 1, "СИСТЕМА АКТИВНА")

-- Заливка области символом
m.broadcast(404, "pt", termId, "fill", 1, 3, 30, 1, "=")

-- Построчный вывод с автопрокруткой (scroll print)
m.broadcast(404, "pt", termId, "print", "Внимание: тревога!")

-- Смена цвета текста и фона (RGB)
m.broadcast(404, "pt", termId, "color", 0x00FF66, 0x08150A)

-- Звуковой сигнал (бип)
m.broadcast(404, "pt", termId, "beep", 1.2)

-- Смена заголовка рамки
m.broadcast(404, "pt", termId, "title", "РАДАР ПЕЙДЖЕР")
```

Вместо `termId` можно передать `"all"` для широковещательной рассылки на все активные карманные терминалы!
