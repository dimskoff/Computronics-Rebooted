# Радар (Radar)

**Радар** — блок активного обнаружения сущностей в трёхмерной сфере вокруг блока. Позволяет обнаруживать игроков, враждебных и мирных мобов, вычисляя их относительные координаты и дистанцию.

Имя компонента: `radar`

## Энергопотребление
Сканирование потребляет энергию сети OpenComputers пропорционально радиусу поиска (~1.5–3.0 энергии на блок радиуса). Максимальный радиус сканирования: 64 блока.

## Методы компонента

- `getEntities([radius: number]): table`  
  Сканирует всех живых существ в радиусе `radius` (по умолчанию: 16, макс: 64). Возвращает массив таблиц:
  ```lua
  {
    name = "Zombie",
    type = "minecraft:zombie",
    x = 3.5,
    y = 0.0,
    z = -12.1,
    distance = 12.6
  }
  ```
- `getPlayers([radius: number]): table`  
  Специализированный запрос, ищущий только игроков. Возвращает массив таблиц с именами игроков, их относительными координатами (`x`, `y`, `z`) и точной дистанцией (`distance`).

## Пример на Lua

```lua
local component = require("component")
local radar = component.radar

local targets = radar.getPlayers(32)
if not targets then
  print("Ошибка радара: недостаточно энергии в сети!")
  return
end

print("Обнаружено игроков: " .. #targets)
for _, p in ipairs(targets) do
  print(string.format("Игрок: %s | Смещение: (%.1f, %.1f, %.1f) | Дистанция: %.1f м", p.name, p.x, p.y, p.z, p.distance))
end
```
