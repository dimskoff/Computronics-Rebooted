# Аналоговый манометр (Analog Gauge)

**Аналоговый манометр/индикатор** — блок физического стрелочного циферблата для приборных панелей, пультов управления реакторами, контроля уровня энергии, жидкостей и давления.

Имя компонента: `analog_gauge`

## Методы компонента

- `getValue(): number`  
  Возвращает текущее положение стрелки от `0.0` (минимум) до `1.0` (максимум).
- `setValue(val: number): number`  
  Устанавливает стрелку в диапазоне от `0.0` до `1.0`. Мгновенно обновляет положение стрелки в мире.
- `getLabel(): string` / `setLabel(text: string): string`  
  Считывает или задаёт текстовую подпись под шкалой.
- `getColor(): number` / `setColor(rgb: number): number`  
  Задаёт RGB-цвет подсветки шкалы (например, `0xFF0000` для красного цвета тревоги).

## Пример на Lua

```lua
local component = require("component")
local gauge = component.analog_gauge

gauge.setLabel("Температура ядра")
gauge.setColor(0x00FF00) -- Зелёная подсветка
gauge.setValue(0.42)     -- 42%
```
