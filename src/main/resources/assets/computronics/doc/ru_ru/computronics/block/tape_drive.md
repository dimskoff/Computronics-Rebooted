# Ленточный накопитель (Tape Drive)

**Tape Drive** — накопитель на магнитных лентах и аудиопроигрыватель для компьютеров OpenComputers. Подключается к сети с помощью кабелей или при установке вплотную к корпусу компьютера.

Имя компонента: `tape_drive`

## Управление
- **Вставить кассету**: Нажмите ПКМ по блоку, держа магнитную ленту в руке.
- **Извлечь кассету**: Нажмите ПКМ пустой рукой или вызовите метод `eject()` из Lua-кода.

## Методы компонента

- `isReady(): boolean`  
  Возвращает `true`, если кассета вставлена в накопитель.
- `getSize(): number`  
  Возвращает полную ёмкость кассеты в байтах (131072 для железной, 1048576 для кассеты из звезды Незера).
- `getPosition(): number`  
  Возвращает текущую позицию считывающей головки в байтах.
- `seek(offset: number): number`  
  Смещает считывающую головку на указанное количество байт. Отрицательные значения перематывают назад.
- `read([count: number]): string`  
  Считывает до `count` байт (по умолчанию: 1024) с текущей позиции головки.
- `write(data: string): number`  
  Записывает строку или массив байт на кассету. Возвращает количество записанных байт.
- `getState(): string`  
  Возвращает текущее состояние привода: `"STOPPED"` или `"PLAYING"`.
- `play(): boolean`  
  Запускает воспроизведение аудиозаписи с текущей позиции.
- `stop(): boolean`  
  Останавливает воспроизведение.
- `rewind(): boolean`  
  Перематывает ленту на начало (позиция 0).
- `getSpeed(): number` / `setSpeed(speed: number): number`  
  Получает или устанавливает скорость воспроизведения (от `0.25` до `2.0`, норма: `1.0`).
- `getVolume(): number` / `setVolume(volume: number): number`  
  Получает или устанавливает громкость звука (от `0.0` до `1.0`).
- `getLabel(): string` / `setLabel(label: string): string`  
  Считывает или перезаписывает метку кассеты.
- `eject(): boolean`  
  Извлекает кассету в мир перед блоком.

## Программа в OpenOS

В комплекте поставляется дискета с утилитой `tape`:
```sh
tape play              # Начать проигрывание
tape pause             # Пауза
tape stop              # Остановить и перемотать
tape rewind            # Перемотка в начало
tape speed 1.25        # Задать скорость
tape volume 0.8        # Задать громкость
tape label "Резерв 1"  # Назвать кассету
tape write song.dfpwm  # Записать аудиофайл
tape wipe              # Полная очистка кассеты
```

## Пример на Lua

```lua
local component = require("component")
local tape = component.tape_drive

if not tape.isReady() then
  error("Вставьте кассету в дисковод!")
end

print("Ёмкость кассеты: " .. tape.getSize() .. " байт")
tape.rewind()
tape.write("Привет, Computronics!")
tape.rewind()
print("Прочитано: " .. tape.read(30))
```
