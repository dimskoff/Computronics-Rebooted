# Модульная панель управления (Modular Control Panel)

Блок с лицевой сеткой 8x8 ячеек (всего 64 посадочных места), на которые можно устанавливать миниатюрные лампы и кнопки кликом мыши.

## Имя компонента
`control_panel`

## Взаимодействие
* **Установка:** ПКМ с `Миниатюрной лампой` или `Тактильной кнопкой` в руке по лицевой стороне блока устанавливает элемент в соответствующую ячейку сетки.
* **Снятие:** Shift + ПКМ пустой рукой демонтирует установленный элемент и возвращает его игроку.
* **Нажатие:** Обычный ПКМ по кнопке активирует её и отправляет сигнал компьютеру.

## Методы

* `setLampColor(slot: number, color: number): boolean`
  Устанавливает 24-битный RGB цвет лампы в указанном слоте (0 - 63).
* `getLampColor(slot: number): number`
  Возвращает RGB цвет лампы.
* `getElementType(slot: number): number`
  Возвращает тип элемента: 0 (пусто), 1 (лампа), 2 (кнопка).
* `getElements(): table`
  Возвращает полную таблицу всех 64 слотов с типами и цветами.
* `clear(): boolean`
  Гасит все лампы на панели.

## Сигналы
При нажатии игроком на кнопку генерируется сигнал:
`panel_button(slot: number, playerName: string, gridX: number, gridY: number)`
