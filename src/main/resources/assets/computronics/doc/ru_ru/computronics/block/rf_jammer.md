# RF-глушилка (RF Jammer)

**RF Jammer** — генератор радиочастотных помех. При включении создаёт электромагнитный шум в радиоэфире, искажая и повреждая пакеты беспроводных модемов компьютеров, планшетов и дронов.

Имя компонента: `rf_jammer`

## Механика подавления
- **Настройка частоты**: Глушилку можно настроить на определённую частоту (порт) для точечного подавления каналов противника либо установить значение `0` для широкополосного шума по всему диапазону.
- **Искажение данных**: Проходящие сквозь зону помех пакеты повреждаются — байты инвертируются, а текстовые строки забиваются мусорными символами (например, `"Привет мир"` превращается в `"П%%$вёт Fи01!"`).
- **Мощность и радиус**: Радиус глушения рассчитывается по формуле $\min(64, \sqrt{\text{мощность}} \times 6)$ блоков. Высокая мощность пропорционально расходует энергию из буфера сети.

## Методы компонента

- `getFrequency(): number` / `setFrequency(freq: number): number`  
  Получает или задаёт целевую частоту (порт). Значение `0` глушит весь диапазон.
- `getPower(): number` / `setPower(power: number): number`  
  Задаёт выходную мощность генератора (от `1.0` до `100.0`).
- `isEnabled(): boolean` / `setEnabled(state: boolean): boolean`  
  Включает или выключает глушилку.
- `getEffectiveRadius(): number`  
  Возвращает расчётный радиус зоны помех в блоках.

## Пример на Lua

```lua
local component = require("component")
local jammer = component.rf_jammer

jammer.setFrequency(4096) -- Глушим закрытый канал 4096
jammer.setPower(50.0)
jammer.setEnabled(true)

print("Глушилка активна! Радиус действия: " .. jammer.getEffectiveRadius() .. " блоков.")
```
