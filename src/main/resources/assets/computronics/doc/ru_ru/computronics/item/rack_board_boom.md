# Плата самоуничтожения для серверной стойки

Плата расширения для монтажа в **Серверную стойку** (Server Rack) со встроенным термическим зарядом для протоколов экстренной зачистки данных и физического подрыва серверов.

Устанавливается в любой из 4 слотов стойки.

## Имя компонента
`boom_board`

## Методы
* `detonate(): boolean` — немедленно подрывает стойку мощным направленным взрывом.
* `setCountdown(seconds: number): boolean, number` — активирует таймер обратного отсчёта до подрыва в секундах (от 1 до 60).
* `disarm(): boolean` — деактивирует активный таймер обратного отсчёта.
* `getCountdown(): number` — возвращает оставшееся время до взрыва (в секундах) или -1, если взрыв не взведён.

## Пример
```lua
local component = require("component")
local boom = component.boom_board

print("Активация подрыва через 10 секунд...")
boom.setCountdown(10)
```
