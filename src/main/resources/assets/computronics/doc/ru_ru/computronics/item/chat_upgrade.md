# Чат-апгрейд (Chat Upgrade)

**Чат-апгрейд** — модуль расширения для роботов и дронов OpenComputers. Позволяет мобильным машинам отправлять сообщения в чат и писать игрокам в ЛС, используя компонент `chat_box`.

Имя компонента: `chat_box`
Подробный список методов смотрите в документации [Чат-бокса](../block/chat_box.md).
