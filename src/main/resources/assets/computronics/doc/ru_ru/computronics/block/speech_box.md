# Голосовой блок (Speech Box)

Синтезатор речи, озвучивающий произвольные тексты на основе фонетических волн и передающий субтитры игрокам в радиусе 32 блоков.

## Имя компонента
`speech_box`

## Методы

* `say(text: string, [pitch: number]): boolean`
  Произносит текст с регулируемой высотой тона (pitch 0.5 - 2.0).
* `getPitch(): number`
  Возвращает текущую базовую высоту тона.
* `setPitch(pitch: number): number`
  Устанавливает базовую высоту тона речи.
* `isSpeaking(): boolean`
  Проверяет, звучит ли в данный момент речь.
* `stop(): boolean`
  Прерывает воспроизведение речи.
