# Улучшение 'Синтез речи' (Speech Upgrade)

Улучшение для роботов и дронов, оснащающее их роботизированным голосовым модулем для общения с окружающими игроками.

## Имя компонента
`speech`

## Методы

* `say(text: string, [pitch: number]): boolean`
  Произносит текст вслух в радиусе 32 блоков.
* `getPitch(): number`
  Возвращает текущую базовую высоту тона.
* `setPitch(pitch: number): number`
  Устанавливает базовую высоту тона (0.5 - 2.0).
* `isSpeaking(): boolean`
  Проверяет статус воспроизведения.
* `stop(): boolean`
  Останавливает речь.
