# Миниатюрная индикаторная лампа

Компактная светодиодная RGB-лампа поверхностного монтажа.

Может устанавливаться на существующие **Модульные панели управления** или крепиться прямо на любую твёрдую стену или поверхность блока. При установке на обычную стену лампа автоматически создаёт подложку панели управления, подключаемую к кабельной сети OpenComputers.

## Установка и использование
* **Правый клик** по грани блока: монтирует лампу. Если кликнуть по существующей модульной панели управления, лампа монтируется в соответствующую ячейку сетки 8x8. Если кликнуть по обычной твёрдой стене, создаётся новая панель с установленной лампой.
* **Shift + Правый клик** пустой рукой: демонтирует лампу и выпадает в виде предмета.

## Программирование
При подключении панели к компьютеру OpenComputers доступен компонент `control_panel`:
```lua
local component = require("component")
local cp = component.control_panel

-- Установить ячейку 0 в ярко-зелёный цвет (24-битный RGB: 0x00FF00)
cp.setLampColor(0, 0x00FF00)

-- Выключить лампу
cp.setLampColor(0, 0x000000)
```
Каждая горящая лампа излучает физический свет и отображается трёхмерным святящимся куполом светодиода в мире.
