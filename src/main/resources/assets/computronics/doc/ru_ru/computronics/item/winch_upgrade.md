# Лебёдка для дрона (Drone Winch Upgrade)

**Апгрейд лебёдки (Drone Winch)** оснащает летающих дронов OpenComputers моторизованным тросом и механическим захватом. Позволяет дрону зависать на безопасной высоте и опускать трос в шахты, расщелины или над контейнерами для захвата предметов и сущностей.

Имя компонента: `winch`

## Характеристики троса
- **Максимальная длина**: До **32 блоков** вниз.
- **Захватный крюк**: Захватывает выпавшие предметы и живых существ в радиусе 1 блока под крюком.

## Методы компонента

- `deploy(blocks: number): number`  
  Опускает трос вниз на указанное число блоков (макс: 32). Возвращает текущую длину выпущенного троса.
- `retract(blocks: number): number`  
  Подтягивает трос обратно к дрону. Возвращает новую длину троса.
- `getDeployedLength(): number`  
  Возвращает текущую длину выпущенного троса (`0` — трос полностью втянут).
- `grab(): boolean`  
  Активирует захват. Возвращает `true`, если под крюком обнаружен и зафиксирован объект.
- `release(): boolean`  
  Открывает захват и отпускает груз.

## Пример на Lua

```lua
local component = require("component")
local winch = component.winch

-- Опускаем трос на 8 блоков вниз
winch.deploy(8)
print("Длина троса: " .. winch.getDeployedLength() .. "м. Захват...")

if winch.grab() then
  print("Груз зафиксирован! Подъём троса...")
  winch.retract(8)
  print("Груз поднят к дрону.")
else
  print("Под крюком ничего не найдено.")
  winch.retract(8)
end
```
