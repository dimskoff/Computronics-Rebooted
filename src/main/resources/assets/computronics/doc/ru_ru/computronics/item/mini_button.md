# Тактильная микро-кнопка

Миниатюрная физическая тактильная кнопка для панелей приборов.

Может устанавливаться на существующие **Модульные панели управления** или крепиться прямо на любую твёрдую стену или поверхность блока. При установке на стену кнопка автоматически создаёт подложку панели управления, подключаемую к кабельной сети OpenComputers.

## Установка и использование
* **Правый клик** по грани блока: монтирует кнопку. Если кликнуть по панели управления, кнопка монтируется в соответствующую ячейку сетки 8x8. Если кликнуть по обычной твёрдой стене, создаётся новая панель с кнопкой.
* **Правый клик** по установленной кнопке пустой рукой: нажимает кнопку, издаёт щелчок и отправляет сигнал `panel_button` на шину компьютера.
* **Shift + Правый клик**: демонтирует кнопку и выпадает в виде предмета.

## Обработка сигналов
При нажатии кнопки игроком шина компьютера генерирует событие:
```lua
local event = require("event")

while true do
  local id, address, slot, player = event.pull("panel_button")
  print(string.format("Кнопка в ячейке %d нажата игроком %s!", slot, player))
end
```
Кнопки отображаются реалистичными объёмными механическими колпачками на лицевой панели.
