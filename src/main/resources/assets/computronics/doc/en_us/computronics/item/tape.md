# Magnetic Tapes

**Magnetic Tapes** are high-density removable storage media designed for the [Tape Drive](../block/tape_drive.md). They provide durable sequential binary and audio storage.

## Tiers & Capacities

- **Iron Tape**: 131,072 bytes (128 KB)
- **Gold Tape**: 262,144 bytes (256 KB)
- **Diamond Tape**: 524,288 bytes (512 KB)
- **Nether Star Tape**: 1,048,576 bytes (1 MB)

## Usage
1. Insert the tape into a Tape Drive by right-clicking the drive with the tape in hand.
2. Access the tape in OpenOS using the `tape` command or the `tape_drive` Lua component.
3. Label the tape using `tape.setLabel("Backup #1")` or the command `tape label "Backup #1"`.
